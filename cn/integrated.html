一体化表面处理

药剂、粉末、液体漆——一个责任主体。

多数涂层失效，发生在涂装的前一步。宝利莱是宝利鑫科技旗下的粉末板块，集团同时供应前处理药剂与 PVDF 液体漆线——整条链由一个供应商负责，而不是三家互相指。

前处理

决定附着力的七道工序。

#工序目的
1上件悬挂牢固、各面暴露、无兜液死角
2预脱脂去除大部分油污与颗粒
3主脱脂彻底除油，决定附着力
4水洗①②两级水洗，防止污染后槽
5硅烷/陶化无铬无磷纳米陶瓷膜
6水洗③ + 纯水洗去离子水终洗，防缩孔颗粒
7烘干入粉前烘干，水分致针孔

硅烷/陶化替代传统磷化：不含重金属、淤泥更少，粉末在其上的附着力稳定。

阳极氧化药剂

给既做氧化又做喷涂的工厂。

产品编号功能
BS-Q03 / BS-Q04碱性脱脂剂 / 除油剂
BS-Q07喷涂铬化剂
BS-H09无铬皮膜剂（应对 RoHS）
BS-H03无氟中和增光剂（替代硝酸/硫酸中和）
BS-F01 / BS-F02常温 / 中温封孔剂
BS-H01 / BS-H04无镍常温 / 中温封孔剂
BS-Z01 / Z03 / Z04古铜 / 金黄 / 紫铜着色剂
BS-H02无锡着色剂
BS-H05挂具脱漆剂（替代浓硫酸）

氧化线工序：上挂 → 脱脂 → 碱蚀 → 中和 →（抛光）→ 氧化 → 着色 → 封孔。各槽药剂我们都能供。

#氧化工序作用
1装挂铝或钛挂具，保证导电
2脱脂去除油污与搬运脏污
3碱蚀去除自然氧化膜，表面均匀亚光
4中和出光去除碱蚀后的挂灰
5抛光（可选）化学或电解增亮
6氧化硫酸槽生成多孔氧化膜
7着色（可选）有机染料或电解着色
8封孔封闭孔隙，决定盐雾与失重
